# AutoSITEDUC Landing Page

Site estático, mobile first, para publicação no GitHub Pages.

## Estrutura

```txt
.
├── index.html
├── assets/
│   ├── styles.css
│   ├── main.js
│   └── favicon.svg
└── .nojekyll
```

## Publicação sugerida

### Opção recomendada para `salvadorinteligenciatech.com/autositeduc`

1. Criar o repositório `autositeduc`.
2. Enviar estes arquivos para a branch `main`.
3. Em **Settings > Pages**, publicar a partir da branch `main` e pasta `/root`.
4. Configurar o domínio customizado no repositório principal/organização responsável por `salvadorinteligenciatech.com`.
5. O projeto poderá aparecer como `/autositeduc` quando o domínio principal estiver configurado como site de usuário/organização e este for um Project Page.

### Ajustes antes de publicar

- Trocar o número do WhatsApp no `index.html`.
- Confirmar o e-mail oficial de contato.
- Adicionar prints reais do software quando estiver pronto.
- Criar página de privacidade quando o produto entrar em distribuição pública.
