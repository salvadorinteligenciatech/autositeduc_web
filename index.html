O produto

Uma casca desktop para controlar a automação do portal.

O professor informa suas credenciais no AutoSITEDUC, inicia a automação e acompanha o processo em uma interface simples. A proposta é reduzir tempo gasto em tarefas repetitivas, mantendo o usuário no controle.

↯

Automação orientada

Fluxos guiados para carregar dados, cadastrar avaliações e lançar notas no SIGEDUC com menos esforço manual.

◈

Interface objetiva

Telas pensadas para professores: filtros por escola, turno, disciplina e turma, com organização clara das etapas.

⌁

Dados locais

Informações operacionais podem ser salvas localmente para agilizar a rotina sem transformar o sistema em um portal paralelo.

Como funciona

Do login à execução, cada etapa tem uma função clara.

O AutoSITEDUC não substitui o SIGEDUC. Ele atua como uma camada de produtividade: abre o portal, navega pelas rotinas e executa tarefas comandadas pelo professor.

1

Autenticação

O usuário informa login e senha do portal para iniciar a sessão de automação.

2

Coleta de dados

O sistema identifica turmas, turnos, componentes curriculares e opções disponíveis.

3

Execução assistida

O professor escolhe a ação e o AutoSITEDUC realiza os passos repetitivos no portal.

Segurança e confiança

Privacidade como premissa, não como detalhe.

A arquitetura foi pensada para manter a automação próxima do usuário. As credenciais são usadas para abrir a sessão no portal e a proposta do produto é evitar armazenamento de senhas.

✓

Controle de acesso por usuário autorizado.

✓

Execução local no computador do professor.

✓

Foco em reduzir ações repetitivas, sem alterar a responsabilidade do usuário.

✓

Interface transparente para acompanhar cada etapa do processo.
